## Production impact

- **Scale:** built and operated Test Observability ingestion handling 10M+ test events/day at 99.9% ingestion success.
- **Latency:** cut ingestion latency ~40% with stamp-at-source routing.
- **Cost:** moved storage to MySQL as source of truth, retiring ~4 TB of data, cutting infra cost 30% and cross-service RPC traffic 60%.
- **Reliability:** defined SLIs/SLOs for ingestion success, freshness, and API latency; false-positive pages down 50%+.
- **Resilience:** automated regional disaster-recovery bring-up from ~12 h to ≤2 h; led P1 incident response and RCAs.
